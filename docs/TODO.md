목표: 체류시간 늘리기. 앱 설치 없이 웹에서, 보기는 누구나 / 쓰기는 로그인.

- 로그인: 카카오 로그인 (닉네임만, 개인정보 저장 안 함) — 기존 카카오 개발자 앱에 로그인 기능 켜기
- 1단계: 카카오 로그인 + 단지별 한 줄 평 + 항목 별점(교통·학군·주차·관리) + 신고
- 2단계: 사진 첨부 + 댓글 + 좋아요
- 3단계: 홈 '최근 리뷰' 피드, 관심단지 새 리뷰 알림
- 필수: 이용약관·개인정보처리방침 페이지, 신고 누적 자동 숨김 + 관리자 삭제, 사진 개인정보(동호수·얼굴·차번호) 안내
